# мониторинг кадровой динамики педагогов

Репозиторий содержит файл с препроцессингом, EDA данных и интерактивный прототип многостраничной системы поддержки принятия решений на Streamlit

## Структура проекта

```text

│   └── dataset.csv              # подготовленный датасет для дашборда
├── pages/
│   ├── dashboard_director.py    # панель руководителя образовательной организации
│   └── dashboard_department.py  # сводный мониторинг органа управления образованием
├── start.py                     # главная страница приложения и настройка навигации
├── EDA.ipynb                    # ноутбук с препроцессиованием данных

├── screenshot_director.png      # скрин панели руководителя
└── screenshot_department.png    # скрин панели регионального монтиоринга



## Пользовательские сценарии:

# Руководитель образовательной организации:

1) Выбор конкретной школы из отсортированного по размеру штата списка и учебного года.

2) Оценка кадровой устойчивости: численность коллектива, процент оттока, количество педагогов с высокой нагрузкой 

3) Точечный анализ соотношения педагогического стажа и числа предметов

4) Распределение средней нагрузки по предметным кафедрам школы.

# Орган управления образованием:

1) Региональный срез с фильтрацией по учебному году, округам и минимальному размеру штата (нужен для отсечения очень маленьких организаций)

2) Межшкольное сопоставление - зависимость процента текучести школы от средней учебной нагрузки на учителя

3) Сравнение округов по доле выбытия педагогов и доле специалистов с высшей квалификационной категорией
